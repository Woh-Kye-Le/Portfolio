Game Description:
CaveBound is a thrilling 2D platformer where players navigate a mysterious cave, switching
between two unique characters to solve puzzles, defeat enemies, and escape treacherous
traps. Strategic character abilities, vibrant environments, and fast-paced gameplay make
CaveBound a test of wits and skill!

==================================================================================
Game Controls:
- **Arrow Keys/AD**   : Move characters
- **Spacebar**          : Jump
- **Q**                 : Switch characters
- **M**                 : Start game
- **Escape**            : Quit to main menu

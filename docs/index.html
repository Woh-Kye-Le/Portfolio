Probability Lab

Personal project · Probability & simulation

Streamlit lab that works through my probability course one topic at a time: counting, Bayes' rule, the Binomial/Geometric/Poisson family, continuous distributions, expectation and variance, and joint distributions. Every topic computes the answer from the formula, then estimates the same quantity by simulation and only accepts it when the estimate lands within 2 standard errors of the exact value. The PMFs, PDFs and CDFs are written from scratch, with scipy appearing only in the tests that check them.

  • Python
  • NumPy
  • Streamlit
  • Matplotlib
  • pytest

Can I Beat the Compiler?

Personal project · x86-64 Assembly benchmark

I hand-wrote five routines in x64 MASM (strlen, array sum, popcount, array reverse and an RGBA to grayscale conversion) and raced them against the optimized C++ versions (/O2 /arch:AVX2) to find out why each one wins or loses. Hand-written SSE2 grayscale won 4.2x and strlen 1.64x, the compiler won the auto-vectorized array sum by 3.3x, and popcount/reverse were ties.

  • Assembly (x64)
  • MASM
  • SSE2 / SIMD
  • C++17
  • Benchmarking
